For trianing and testing, your directory structure should look like this

`Datasets` <br/>
     `├──train` <br/>
          `├──inputC` <br/>
          `├──inputL` <br/>
          `├──inputR` <br/>
          `└──target` <br/>
     `├──test` <br/>
          `├──indoor_labels.npy` <br/>
          `├──outdoor_labels.npy` <br/>
          `├──inputC` <br/>
          `├──inputL` <br/>
          `├──inputR` <br/>
          `└──target` <br/>
     `└──train_patches` <br/>
          `├──inputC_crops` <br/>
          `├──inputL_crops` <br/>
          `├──inputR_crops` <br/>
          `└──target_crops` <br/>

train_patches are generated by running ```python generate_patches_dpdd.py```
